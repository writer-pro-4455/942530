# Model artifacts

Generated model files are ignored by default to avoid committing large binaries accidentally.

Expected names used by the scripts:

- `custom_cnn_best.keras`
- `mobilenet_v2_best.keras`
- `mobilenet_v3_small_best.keras`
- `efficientnet_b0_best.keras`
- `mobilenet_v3_small_fp16.tflite`
- `mobilenet_v3_small_int8.tflite`

If journal policy and repository limits permit, add the exact trained checkpoints used for the reported manuscript results and record their SHA-256 hashes.
