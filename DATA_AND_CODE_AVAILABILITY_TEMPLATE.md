# Data and Code Availability statement template

The primary Corn or Maize Leaf Disease Dataset used in this study is publicly available on Kaggle at https://www.kaggle.com/datasets/smaranjitghose/corn-or-maize-leaf-disease-dataset. The PlantDoc dataset used for secondary cross-dataset evaluation is described by Singh et al. (2020), https://doi.org/10.1145/3371158.3371196. Source code for data splitting, model training, evaluation, TensorFlow Lite quantization, CPU benchmarking, ScoreCAM generation, MQTT telemetry, and ThingsBoard integration is available at **https://github.com/writer-pro-4455/942530**. The repository also contains the exact experimental configuration and reproduction instructions. Environmental telemetry used in the IoT proof-of-concept was simulated solely to validate the MQTT/ThingsBoard communication path and was not used as an input to the disease classifier.
